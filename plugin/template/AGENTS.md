# このリポジトリで作業するエージェントへ

このゲームは HIKARI エンジンで作っている。チームの作業は **HIKARI 制作ハブ**（`.hikari-hub.toml` の `url`）でまとめている。

- **Claude Code**：`hub` プラグインを入れ、`/hub:today` から始める。カードを取る・ブランチを切る・報告を書くまでの手順はプラグインのスキル（`hub:work`）にある。
- **ほかのエージェント**：ハブには書けない。`.hikari-hub/cache/`（Claude Code が同期した控え）があれば、その `rules/` と `engine/` を読んでから作業し、終わりに「結論・変更・確認したこと・未確認・残り」を人に渡す。

## 作業はカードから

- **カードを取るまで、ファイルは変更できない。** リポジトリの見張りフック（`.claude/hooks/`）が止める。`/hub:start` でカードを取ると、作業ブランチが切られ、変更できるようになる。
- 頼まれた作業がカードになければ、先にカードを作ってから取る。
- `main` では変更できない。保護されたファイルとカードの範囲外のファイルは、人の確認が要る。
- 止められたときに、シェルで書き換えるなどして回避しない。

## いつも守ること

- ルールはハブの「ルール」にある（オーナーがページで書き換える）。作業の前に必ず読む。
- エンジンのソースは直さない。include するのは `HIKARI/Project/*` と `HIKARI/Runtime/ComponentTypeId.h` だけ。足りない機能はハブの「エンジンへの要望」に出す。
- `main` に直接コミットしない。1 カード 1 ブランチ（`<種別>/<カード id>-<英語の短い名前>`）。
- 速さ・時間・距離・色などの調整値をコードに直書きしない。コンポーネントのフィールドかアセットに出す。
- シーン・プレハブ・アセットのファイルを手で書き換えない。
- 確かめていないことを「できた」と言わない。
- `Library/`、`.hikari-hub/`、`CMakeUserPresets.json` はコミットしない。
