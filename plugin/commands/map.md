---
description: ハブの「地図」を新しくする（各ブランチのファイルのまとまり・つながり・develop との違い）
---

`hub:work` スキルを読み込む（準備がまだなら「0. 準備」から）。

1. `hub map` を実行する（origin を取り込み直し、元ブランチ・公開ブランチ・メンバーそれぞれの自分のブランチを読んで送る。チェックアウトはしない）。
2. 結果の行（`mapped <ブランチ>  nodes …, changed …, ahead …, behind …`）から、人に短く伝える：
   - 自分のブランチが `develop` より何コミット先にあるか、何コミット遅れているか
   - ほかのメンバーのブランチと同じファイルを変えていないか（`git diff --name-only origin/<元ブランチ>...origin/<ブランチ>` で突き合わせる）
   - `skip … (not on origin yet)` のブランチがあれば、まだ push されていないこと
3. ページの「地図」で見られることを伝える（ページの URL は `hub whoami` の `page`）。
