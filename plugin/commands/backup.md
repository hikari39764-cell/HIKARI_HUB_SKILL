---
description: （オーナー専用）ハブのデータを手元のフォルダに書き出して控えを取る
argument-hint: "[控えを置くフォルダ]"
---

**オーナーだけが実行する。** メンバーは記録を消せないが、書き換えることはできるので、控えは定期的に取る。

1. 置き場所：引数、なければ `git config --global hikarihub.backup`。どちらも無ければ人に聞いて、`git config --global hikarihub.backup <フォルダ>` に覚える。ゲームのリポジトリの中には置かない。
2. `hub whoami` で作品 id（`project`）を読む。書き出し先は `<置き場所>/<作品 id>/`。
3. `hub sync -All -Dir "<置き場所>/<作品 id>"` を実行する（全部のコレクションと、ページで入れた画像を書き出す。消された記録は書き出し先からも消える）。
4. `<置き場所>` が git リポジトリでなければ `git init` する。`git add -A` して、`<作品 id>: 控え <日付>` でコミットする（push はしない）。
5. 件数（コレクションごと）と、前回から減ったコレクションがあればそれを人に伝える。
