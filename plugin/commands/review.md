---
description: PR やブランチの差分を、ハブのルールとミス帳に照らしてレビューする
argument-hint: "[PR 番号・ブランチ・カードの名前]"
---

`hub:work` スキルを読み込む（準備がまだなら「0. 準備」から）。

対象：$ARGUMENTS（空なら、`確認待ち・レビュー` のカードのうち自分が担当でないものを見せて選んでもらう）

1. 差分を読む（`gh pr diff <番号>`、または `git diff origin/<元ブランチ>...<ブランチ>`）。カードの完了条件と終了報告も読む。
2. 見ること：
   - ルールの「コードの約束」（調整値の直書き、非公開ヘッダ、同じ処理の重複、残された古いコード）
   - エンジン知識の「落とし穴」（Attach でのゲーム処理、Play 中かの確認、持ち出してはいけない View、`Accepted()`）
   - ミス帳にある同じ領域のミスを繰り返していないか
   - 完了条件を満たしているか、終了報告の「確認したこと」が差分と合っているか
3. 指摘は「どの入力・状態で、何が起きるか」が言えるものだけ。好みの話はしない。
4. 結果を人に見せる。人が承認したら、PR へのコメント（`gh pr review`）は人の指示があるときだけ行う。
5. レビューで見つかった問題は、書いた本人のミス帳に残すよう勧める。カードを `完了` にするのは PR がマージされてから。
