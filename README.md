# HIKARI 制作ハブ

HIKARI エンジンでゲームを作るチームのための作業台。作品ごとに claude.ai のページ（ハブ）があり、カード・報告・不具合・質問・ナレッジ・ミス帳・ルール・エンジン知識を、人と全員のエージェントが同じ場所で読み書きする。

このリポジトリには次のものが入っている。

- `plugin/`：Claude Code のプラグイン（スキル `hub:work` とコマンド `/hub:…`）。ハブのページの雛形と初期データも含む
- `schema/schema.json`：ハブの記録の項目の宣言（ページもエージェント向けの資料もここから作る）
- `content/`：既定のルールとエンジンの必須知識（新しいプロジェクトに入る初期データ）
- `page/`、`tools/`：ページの元と、ビルド

## 参加の手順（メンバー）

1. オーナーから届いた招待メールのリンクを開き、Claude のアカウントでログインする。ハブのページが開く。
2. ページの「メンバー」で、自分の**呼び名**（半角英数字）を登録する。
3. GitHub のゲームのリポジトリの招待を承認し、clone する（初回だけ `git lfs install`）。
4. Claude Code（ページと同じ Claude のアカウントでログイン）で、このプラグインを入れる：

   ```
   /plugin marketplace add <このリポジトリの owner/name>
   /plugin install hub@hikari-hub
   ```

   このリポジトリは非公開なので、GitHub に読める権限でログインしていること（`gh auth login` など）。
5. ゲームのリポジトリの中で Claude Code に `/hub:today` と言う。最初に呼び名を聞かれる（ページで登録したものと同じにする）。

## 毎日の使い方

| コマンド | すること |
|---|---|
| `/hub:today` | 自分のカード、確認待ち、答えられる質問、締切を見る |
| `/hub:start [カード]` | カードを取り、ブランチを切り、ルールと関係する知識を読んで作業を始める |
| `/hub:progress` | 進捗を 1〜2 行で記録する |
| `/hub:end` | 確かめる・コミット・push・PR・終了報告・カードの更新 |
| `/hub:ask <質問>` | まずハブで探し、なければ質問板に出す |
| `/hub:bug <起きたこと>` | 見つけた問題を登録する（エンジン側はエンジンへの要望へ） |
| `/hub:review [PR]` | ルールとミス帳に照らしてレビューする |
| `/hub:plan <目標>` | 目標をカードの下書きに分ける |

人はページで同じことができる：カードを作る、不具合や質問を書く、答える、決める、日報を書く。

## オーナーがすること

- **新しいプロジェクト**：ゲームのリポジトリの直下で `/hub:new <作品名>`。ページの公開、初期のルールとエンジン知識の投入、リポジトリへの設定ファイルの配置まで行う。
- **招待**：ページの共有メニューから、メールで**編集者**として招待する。「リンクを知っている全員」にはしない（外部の編集者が書けなくなる）。見るだけの人は閲覧者で招待する。
- **ルール**：ページの「ルール」で直接書き換える。メンバーとエージェントは「ルール提案」を出せる。
- **計画**：ページの「ボード」で、カードを「予定」に入れる・順番を決める・担当を決める。締切もここで編集する。
- **エンジン知識**：ページの「エンジン知識」で直す。プラグインを更新したあと `/hub:upgrade` で、新しい既定の内容を選んで取り込める。
- **控え**：`/hub:backup`。編集者は技術的には記録を消せるので、定期的に取る。

設定・計画・ルール・エンジン知識は、オーナーだけが書ける（データベースの規則で止まる）。それ以外の記録は編集者全員が書ける。

## 開発（このリポジトリを直す人）

```bash
python -I -X utf8 tools/build.py
```

- `schema/schema.json` か `content/` か `page/hub.src.html` を変えたら必ずビルドして、生成物（`plugin/owner/`、`plugin/skills/work/references/data-model.md`・`engine.md`）も一緒にコミットする。
- `dist/preview-owner.html` と `dist/preview-member.html` は、見本データで動く手元の確認用（`python -m http.server --directory dist` で開く）。
- コミットメッセージは `<種別>(<範囲>): <日本語> / <中文>`。
