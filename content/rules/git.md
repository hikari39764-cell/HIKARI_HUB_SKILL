## ブランチ

- 元ブランチ（既定 `main`）はいつでも遊べる状態に保つ。直接 push しない。
- 作業ブランチは `<種別>/<カード id>-<英語の短い名前>`（例 `feat/c-k3j9a-enemy-knockback`）。1 カード 1 ブランチ。
- 取り込みは PR で、レビュー 1 人の承認のあと squash でマージする。マージしたブランチは消す。
- main への force push、他人のブランチの書き換えはしない。

## コミットメッセージ

```
<種別>(<範囲>): <何をしたか・日本語 50 字以内>

<なぜ・どう確かめたか（任意）>

Card: <カード id>
```

- 種別：`feat` 新しい機能／`fix` 不具合の修正／`tune` 数値・見た目の調整／`asset` 素材／`level` シーン・レベル／`refactor` 動きを変えない整理／`perf` 速さ／`docs` 文書／`chore` 設定・ビルド
- 例：`fix(プレイヤー): 壁際で被弾すると床に埋まる問題を直す`
- 作業した人の git の名前でコミットする。AI の共同作者行は付けない（どのエージェントが作業したかはハブの報告に残る）。
- 関係ない変更を混ぜない。API キーやパスワードをコミットしない。

<!-- id: rule-git-pr; core: false; order: 30 -->
## PR と素材

- PR のタイトルはコミットの 1 行目と同じ。本文は終了報告から埋める（結論・変更・確認したこと・未確認）。見た目が変わるときはスクリーンショットを付ける。
- 画像・モデル・音・動画は Git LFS。PSD や Blend のように結合できないファイルは LFS のロックを取ってから編集する。
- `Library/`、ビルド結果、`CMakeUserPresets.json`、個人の設定はコミットしない。
- タグ：`playtest-01`（試遊会）、`submit-20261201`（提出）、`v0.1.0`（公開版）。
